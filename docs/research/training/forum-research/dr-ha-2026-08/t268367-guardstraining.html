If it is a point guard, you should train passing and handling up. These greatly influence offensive flow. Jump shot and driving are useful as well.

If it is a shooting guard, jump shot, driving, handling, and passing are all good skills to work on for him.

The order I put them in is the order I think are most important for each type of guard.

There are some differences as to what you aim to achieve and what type of player you are training. It would be easiest for us if you posted the skills of your trainee so that we can give a custom made plan for him.
If you want an as fast trained player as possible or an as useful player as possible for your team will make a lot of difference in what skill you start with.
If you want a useful player then i suggest that you give him some OD and PA first. But if your aiming to train the best possible player(something that i suppose is many seasons away for you) you may want to start with skills that are behind first and then train HA up over the others so that it gives a good elastic effect to the other skills.
But that is probably more then you need to know for now.
Like i said earlier, if you want to post his skills we can help you with a training plan and complete build for him if you like.
